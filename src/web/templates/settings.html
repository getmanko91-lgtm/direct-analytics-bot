MAX

Токен и chat_id можно указать здесь. Chat_id — в документации dev.max.ru.

AppMetrica

Для установок и покупок в отчёте «Отчеты клиентам». Можно также задать в .env как YANDEX_APPMETRICA_TOKEN.

Telegram

Создайте бота у @BotFather, вставьте токен. Напишите боту /start, chat_id можно взять у @userinfobot. Для группы добавьте бота в чат.

С российского VPS Telegram обычно недоступен. Релей: Cloudflare Worker (deploy/telegram-relay/worker.js) или GitHub Actions (.github/workflows/telegram-relay.yml, URL https://api.github.com/repos/OWNER/REPO/dispatches). Без релея уведомления уйдут в MAX, если он настроен.

OAuth-токен Директа — в .env. После изменения времени отправки перезапустите сервис.
